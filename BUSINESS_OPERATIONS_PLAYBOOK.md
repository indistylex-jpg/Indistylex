### Golden Rule: One Inventory, Many Channels

Never sell the same SKU on two channels without syncing stock. Use this priority when stock is low:

1. **Website orders** (highest margin) — fulfill first
2. **Amazon / Flipkart** — fulfill within SLA (24–48h)
3. **B2B bulk** — only if surplus stock

## 4. Pricing & Margins

### Pricing Formula

```
Selling Price = (Cost Price + Packaging + Shipping) × (1 + Target Margin) + GST
```

### Example: Kids Cotton Frock

| Item | Amount |
|------|--------|
| Wholesale cost (per piece) | ₹250 |
| Packaging (polybag + tag) | ₹15 |
| Shipping (avg per piece) | ₹60 |
| **Total cost** | **₹325** |
| Target margin (50%) | ₹162 |
| **Selling price (ex-GST)** | **₹487 → round to ₹499** |
| GST @ 5% (if price ≤ ₹1000) | ₹25 |
| **MRP / Website price** | **₹499** |

### Margin Targets by Channel

| Channel | Target margin | Notes |
|---------|---------------|-------|
| Website | 45–60% | Your best margin |
| Amazon | 30–40% | Deduct 15–20% referral + closing fees |
| Flipkart | 30–40% | Deduct 15–20% commission |
| B2B wholesale | 15–25% | Volume makes up for lower margin |

### Pricing Rules

- **Never go below 20% margin** on any channel — you will lose money after returns
- **MRP must be same** across website, Amazon, Flipkart (marketplace policy)
- **Offer discounts via coupons**, not permanent price cuts
- **Festival sales**: max 30–40% off, planned around seasonal calendar (see marketing docs)

## 5. Inventory & Procurement

### 5.1 Procurement Process

```
1. IDENTIFY DEMAND
   └── Check sales data (website admin, Amazon reports, shop orders)
   └── Seasonal planning (summer stock in March, winter in September)

2. SOURCE FROM WHOLESALER
   └── Visit market / order via WhatsApp / phone
   └── Negotiate: MOQ (minimum order qty), price, return policy
   └── Get GST invoice from wholesaler (for input tax credit)

3. RECEIVE & INSPECT
   └── Count pieces vs invoice
   └── Check quality (stitching, fabric, sizing, colors)
   └── Reject damaged items immediately

4. ENTER IN SYSTEM
   └── Add to website admin (products, variants, stock count)
   └── Update inventory spreadsheet (for B2B + marketplace)
   └── Photograph products (white background + lifestyle)

5. STORE PROPERLY
   └── Organize by SKU / size / category
   └── Label bins/shelves
   └── Keep fast-moving items accessible
```

### 5.3 Reorder Rules

| Stock level | Action |
|-------------|--------|
| Above reorder level | Normal — no action |
| At reorder level | Place order with wholesaler |
| Below 5 units | Mark "Low Stock" on website; pause marketplace ads for that SKU |
| Zero | Mark "Out of Stock" on all channels immediately |

### 5.4 Quality Control Checklist

Before adding any product to inventory:

- [ ] Fabric quality acceptable (no pilling, color bleed)
- [ ] Stitching intact (no loose threads)
- [ ] Size label correct and readable
- [ ] No stains, holes, or defects
- [ ] Matches sample / photo from wholesaler
- [ ] Wash care label present (legally required)
- [ ] Your brand tag attached (optional but professional)

### 8.4 Coupon Codes (Admin → Coupons)

Discount codes for **website campaigns only** — customers apply them on the **Cart** page before checkout.

#### Why use coupons (benefits)

| Benefit | What you get |
|---------|--------------|
| **More conversions** | First-time buyers order when they see “10% off with WELCOME10” |
| **Protect MRP** | Temporary discount — no permanent price cut on website or marketplaces |
| **Track marketing** | Different codes per channel (`INSTA10`, `WHATSAPP15`) → see what works |
| **Control cost** | End date, max uses, minimum cart — festival codes don’t run forever |
| **Influencer / referrals** | Unique limited codes (`PRIYA20`, max 50 uses) |

> Aligns with §4 Pricing Rules: *offer discounts via coupons, not permanent price cuts.*

#### How to create (5 minutes)

1. Open **https://indistylex.com/admin** → sidebar **Coupons** → **Add Coupon**.
2. Fill in:

| Field | Example | Notes |
|-------|---------|-------|
| Coupon Code | `WELCOME10` | Uppercase; share this publicly |
| Discount Type | Percentage | Or flat ₹ off |
| Discount Value | `10` | 10% or ₹100 |
| Min Order Amount | `499` | Optional — cart must reach this |
| Max Uses | `100` or `0` | `0` = unlimited |
| Valid From / Until | Campaign dates | Auto-expires after sale |
| Active | ✓ | Uncheck to pause instantly |

3. **Create Coupon** → share code on Instagram (`@indistylex_clothing`), WhatsApp, email.
4. Customer: Cart → enter code → **Apply** → discount shows → checkout.

#### Starter codes to create

| Code | Type | Value | Min ₹ | Max uses | Campaign |
|------|------|-------|-------|----------|----------|
| `WELCOME10` | 10% | — | 499 | ∞ | New visitors / email signup |
| `INSTA10` | 10% | — | 599 | 500 | Instagram bio link |
| `FIRST50` | Flat ₹50 | — | 799 | 200 | Launch — friends & family |
| `DIWALI25` | 25% | — | 1499 | 300 | Festival (set 7-day dates) |

#### Track performance

- **Admin → Coupons** — column **Uses** (e.g. `12 / 100`).
- **Admin → Orders** — order detail shows coupon code used.
- Log redemptions in **Weekly KPIs** tab when comparing campaigns.

## 9. B2B Wholesale (Shop Sales)

### 9.1 B2B Sales Process

```
1. Shop owner contacts you (phone / WhatsApp / visit)
2. Show catalog (WhatsApp photos / physical samples)
3. Quote wholesale price (15–25% margin)
4. Confirm order (items, qty, sizes, colors)
5. Generate GST invoice
6. Pack in bulk (no fancy packaging needed)
7. Ship via Delhivery / local transport / self-delivery
8. Collect payment (COD on delivery or 7–15 day credit)
9. Follow up for repeat orders
```

| High return rate (15%+) | Medium | High | Quality check every piece; accurate size charts; good product photos |
| Marketplace account suspension | High | Low | Follow listing policies strictly; never fake reviews |
| Stockouts on popular items | Medium | High | Reorder at 10-unit threshold; daily inventory sync |
| Cash flow gap (B2B credit) | High | Medium | Prefer COD for B2B; limit credit to trusted shops |
| GST penalty for late filing | Medium | Medium | Hire CA from month 1; set calendar reminders |
| Competitor undercutting price | Low | High | Compete on quality + brand, not price |
| Server downtime | Medium | Low | UptimeRobot alerts; daily backups (your DevOps skills) |
| Wholesaler quality issues | Medium | Medium | Inspect every batch; maintain 2+ supplier options |
| Burnout (doing everything solo) | High | High | Follow daily routine (45 min); hire help at 50 orders/month |
