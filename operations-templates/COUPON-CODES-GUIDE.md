# Indistylex — Coupon Codes Guide

> **Where:** https://indistylex.com/admin → **Coupons**  
> **Who:** Owner / Manager (admin login)  
> **Also in:** [BUSINESS_OPERATIONS_PLAYBOOK.md](../BUSINESS_OPERATIONS_PLAYBOOK.md) §8.4

---

## What is a coupon code?

A **coupon** is a discount code customers enter at **cart checkout** on indistylex.com (e.g. `WELCOME10`). The site automatically reduces the order total — no manual calculation.

**Coupons are for the website only.** Amazon and Flipkart have their own promo tools.

---

## Benefits (why use them)

| Benefit | How it helps Indistylex |
|---------|-------------------------|
| **More orders** | First-time buyers convert when they see “10% off” |
| **Protect MRP** | Discount is temporary — you don’t permanently lower prices on Amazon/Flipkart |
| **Track campaigns** | Separate codes per channel (`INSTA10`, `WHATSAPP15`) — see which marketing works |
| **Control cost** | Set end date, max uses, minimum cart value |
| **Recover abandoned carts** | Email/WhatsApp: “Use CART10 before Sunday” |
| **Influencer / friends** | Unique codes (`PRIYA20`) — limit uses so cost stays predictable |
| **Festive sales** | `DIWALI25` for 7 days without changing product prices in admin |

> **Rule:** Offer discounts via **coupons**, not permanent price cuts (see playbook §4 Pricing Rules).

## Step-by-step: Create a coupon

1. Go to **https://indistylex.com/admin** and log in.
2. Sidebar → **Coupons**.
3. Click **Add Coupon**.
4. Fill the form:

| Field | What to enter | Example |
|-------|---------------|---------|
| **Coupon Code** | Short, uppercase, no spaces | `WELCOME10` |
| **Discount Type** | Percentage (%) or Flat amount (₹) | Percentage |
| **Discount Value** | 10 = 10% off, or ₹100 flat off | `10` |
| **Min Order Amount (₹)** | Cart subtotal must reach this | `499` (optional) |
| **Max Uses** | Total redemptions allowed; **0 = unlimited** | `100` or `0` |
| **Valid From / Until** | Campaign dates | Launch → +30 days |
| **Active** | Uncheck to pause without deleting | ✓ checked |

5. Click **Create Coupon**.
6. Share the code in Instagram bio, WhatsApp, email, or ads.

### Customer side

1. Customer adds items to cart → **Cart** page.
2. Enters code in “Coupon code” box → **Apply**.
3. Discount shows in cart summary → proceeds to checkout.
4. Order stores the coupon code; usage count increases in admin.

## Ready-to-use campaign codes (copy & create)

| Code | Type | Value | Min order | Max uses | Use for |
|------|------|-------|-----------|----------|---------|
| `WELCOME10` | % | 10% | ₹499 | 0 (∞) | New customers — website, email signup |
| `FIRST50` | Flat | ₹50 | ₹799 | 200 | Launch week — friends & family |
| `INSTA10` | % | 10% | ₹599 | 500 | Instagram bio / stories |
| `WHATSAPP15` | % | 15% | ₹999 | 100 | WhatsApp broadcast (higher min = protect margin) |
| `CART10` | % | 10% | ₹499 | 50 | Abandoned cart reminder (7-day validity) |
| `DIWALI25` | % | 25% | ₹1499 | 300 | Festival sale — short date range only |

**Tips:**
- Keep website discounts **≤ 30–40%** except clear festival campaigns.
- Higher **min order** = discount applies only on bigger carts (protects margin).
- Use **max uses** for influencer codes so one person can’t share unlimited times.

## Manage & track coupons

| Action | How |
|--------|-----|
| See all codes | Admin → Coupons (list shows uses: `5 / 100`) |
| Pause a sale | Edit coupon → uncheck **Active**, or set **Valid Until** to yesterday |
| End campaign | Delete coupon or leave inactive |
| See which order used a code | Admin → Orders → open order (coupon stored on order) |

---

## When to create coupons

| When | Suggested action |
|------|------------------|
| Website launch | `WELCOME10` + share on Instagram |
| New collection drop | `NEWARRIVAL10` for 2 weeks |
| Slow week | Limited `FLASH15` — 48 hours, max 50 uses |
| Influencer post | Unique code, max 20–50 uses |
| Email welcome series | Same as `WELCOME10` in Brevo template |

---

## What coupons do NOT do

- Do **not** apply on Amazon / Flipkart (create promos there separately).
- Do **not** replace GST invoice logic — discount is on pre-tax subtotal in checkout.
- Do **not** stack — one coupon per order.
