# Indistylex — Category Catalog (0–18 Years)

> **Use this when adding categories in Admin UI.**  
> Matches how **Amazon India** and **Flipkart** organize kids & teen fashion.  
> **Admin:** https://indistylex.com/admin → Categories → Add Category

---

## How to add categories in Admin (UI)

1. Login → **Admin** → sidebar **Categories**
2. Click **Add Category**
3. Fill:
   - **Name** — from tables below
   - **Description** — copy from table (helps SEO)
   - **Parent Category** — `None` for main groups; pick parent for sub-categories
   - **Sort Order** — use number from table (lower = shows first)
   - **Active** — ✅ checked
4. **Save Category**
5. Add **sub-categories** after all parent categories exist

**Order:** Add all **Level 1 (parent)** first → then **Level 2 (children)**.

## Admin → Add Product (after categories exist)

1. **Admin** → **Products** → **Add Product**
2. Pick **Category** from dropdown
3. Set **Age Group** to match (0–18 options available)
4. Set **Gender**: Kids / Girls / Boys
5. Add variants: **Size + Color + SKU + Stock**
6. Upload images → **Save**

SKU format: `IX-[TYPE]-[NUM]-[SIZE]-[COLOR]` — see `HSN_CODES.md`
