## How to print

1. Open `index.html` in Chrome or Firefox (double-click or `xdg-open index.html`).
2. Click into the file you need → **Print** (Ctrl+P).
3. Paper: **A4**, scale **100%**, margins **Default** or **Minimum**.
4. Optional: **Save as PDF** for print shop or reprints.
