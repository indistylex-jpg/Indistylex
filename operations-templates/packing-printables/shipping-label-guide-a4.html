Steps

  1. Complete packing: tissue → thank-you card → invoice in polybag → seal.
  2. Weigh package on scale; enter weight in courier portal if required.
  3. Print AWB / shipping label (thermal or A4 cut to size).
  4. Peel backing; place label centered on front of polybag.
  5. Smooth flat — no bubbles over barcode.
  6. Mark order Shipped in admin; send tracking link to customer.

Do

  • Label on flat surface
  • Barcode fully visible
  • Sender = Prayagraj address
  • Match weight slab

Don't

  • Fold label over edge
  • Cover barcode with tape
  • Ship without invoice inside
  • Mix up two order labels

Pre-handover checklist

  • Order ID on label matches packed item
  • Invoice inside polybag
  • Thank-you card included
  • Polybag fully sealed
  • Label stuck — barcode scans in portal test
  • Pickup manifest / handover to courier logged
