## How to use Business-Tracker.xlsx

### Who touches which tab

| Tab | Owner | Manager | Assistant |
|-----|-------|---------|-----------|
| Inventory | Review weekly | **Update daily** | Sends counts via WhatsApp |
| Orders | Review weekly | **Add every sale** | Reports sales via WhatsApp |
| Expenses | Review monthly | **Add when spent** | Reports cash spent |
| Weekly KPIs | **Fill Sunday** | Draft numbers Saturday | — |
| B2B Customers | Review | **Maintain** | Provides shop info |
| SKU & HSN Codes | Reference | Reference | — |
| Monthly P&L | **Fill 1st of month** | Draft | — |

### Manager daily routine (15–20 min evening)

```
1. Admin panel → any new website orders? Record in Orders tab
2. Any B2B today? → Record in admin (B2B Sales) + Orders tab + B2B Customers
3. Assistant sent stock count? → Update Inventory tab
4. Any money spent? → Expenses tab
5. Post summary in WhatsApp group
```

### Single rule — avoid double chaos

> **Website stock truth** = Admin panel (`indistylex.com/admin`)  
> **Money & planning truth** = Excel Business-Tracker  
> **Same day sync** — never skip a day

**When:** Sunday 7:00 PM IST — 30 minutes (video call)

**Agenda:**
1. Open **Weekly Review** tab → fill orders, revenue, expenses
2. Open **Business-Tracker → Weekly KPIs** → same numbers
3. Review **30-Day Plan** — how many days marked Done?
4. Assistant's written summary (sent before call)
5. Set **3 priorities** for next week
6. Owner sign-off column

## Escalation — when to involve you (owner)

| Situation | Who handles | Escalate to you? |
|-----------|-------------|------------------|
| New website order | Manager | No |
| B2B sale under 10% extra discount | Manager | No |
| B2B discount over 10% | Manager asks | **Yes** |
| Website down / admin 500 error | Manager reports | **Yes — fix server** |
| Shop wants 30-day credit | Manager | **Yes — approve** |
| Stock mismatch admin vs shop | Manager + Assistant | **Yes if >5 units** |
| Assistant missing 2 daily updates | Manager calls | **Yes — you join call** |
